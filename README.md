# Automation Testing Project

This project is a Java-based test automation framework using **Selenium WebDriver**, **TestNG**, and **Maven**.

## Technologies Used
- Java
- Selenium WebDriver
- TestNG
- Maven
- Jackson (JSON)

## Project Structure
- `src/main` – Main project code
- `src/test` – Automated tests
- `pom.xml` – Maven dependencies and configuration

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Rola-Mahmoud/AutomationAssignment.git
   ```
2. Open the project in IntelliJ IDEA.
3. Install Maven dependencies.
4. Run the tests:
   ```bash
   mvn test
   ```

## Purpose
Automate web application testing to improve test efficiency, consistency, and reliability.
